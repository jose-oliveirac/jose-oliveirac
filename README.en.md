## 👨‍💻 About me

Hi! I'm **José Henrique**, a **Software Developer** from Anápolis, Brazil. I enjoy turning ideas into solutions and **fast, responsive and accessible** interfaces, with clean code and attention to every detail of the user experience.

My curiosity isn't limited to a single area: I like to understand **how things work under the hood**, from how an application runs inside a container to how it can be protected against attacks.

- 💻 Web development: **React, Next.js and TypeScript**

- 🐳 Learning **Docker**: containers, images and development environments
